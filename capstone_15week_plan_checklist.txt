                            범위: MVP + 확장 기능 + 후순위/연구형 기능 포함




1. 프로젝트 개요
본 문서는 캡스톤 프로젝트로 기획 중인 “선택형 데이터·도구 기반 데스크톱 AI 에이전트 시스템”의 15 주 개
발 플랜과 상세 기능 구현 체크리스트를 정리한 문서이다. 시스템은 사용자가 Data Source 와 Tool/API 를 선
택한 뒤 자연어 명령을 입력하면, Git·회의록·태스크·로컬 프로젝트 파일(문서/코드/설정 파일)을 분석하여
진행상황 요약, 질의응답, 작업 추천, 보고서 초안 생성 등을 제공하는 것을 목표로 한다.

   핵심 협업 데이터: 프로젝트, 회의록, 태스크, 선택적으로 마일스톤/일정
   주요 데이터 소스: Git, Meetings, Tasks, Local Project Files
   주요 도구: Git Progress Analyzer, Meeting Summarizer, Task Status Query, Cross-source Summary,
    Document Search, Report Generator
   핵심 설계 원칙: 직접 구현한 retrieval/routing/evidence selection 위에 LLM 을 설명·요약 계층으로 활용
   개발 환경: macOS 기반 개발, Windows 11 대상/시연 환경 고려
   주요 기술 스택: Electron, React, TypeScript, SQLite, Node/Electron main process, LLM API



2. 구현 범위 구분

2.1 반드시 구현할 MVP
   Electron 데스크톱 앱 실행 구조와 기본 UI
   프로젝트 / 회의록 / 태스크 CRUD
   Data Source + Tool/API + Prompt 입력 UI
   Git / Meetings / Tasks 기반 retrieval
   Tool Router 및 기본 handler
   LLM 연동을 통한 요약·질의응답
   Summary / Evidence / Suggested Actions 결과 패널
   핵심 데모 시나리오 3 개 완성

2.2 확장 기능
   Local Project Files(문서/코드/설정 파일) 추가
   chunk 기반 간단한 RAG
   Query History / AI Logs
   회의록 TODO 자동 태스크화
   대시보드 고도화
   최근 변경사항 보고 및 발표자료/보고서 초안 생성

2.3 후순위/연구형 기능
   임베딩 기반 검색, hybrid retrieval, reranking
   mini background indexing daemon
   summary cache 및 query result cache
   마일스톤/리스크 분석
   고급 문서 파서 확대(pdf/docx 안정화)
   부분 자동 반영 워크플로우
